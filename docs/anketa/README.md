# Анкета к финальному пакету, три оформления

Ответы команды на анкету организаторов Хакерского спринта N2, свёрстанные для показа команде.
Текст во всех трёх файлах одинаковый, отличается только стиль. Числа совпадают с `runs/2026-09-04/`
и главным `README.md`; слоган шуточный и на точность не претендует.

- `01-retro-magazine.html` - научно-популярный журнал 50-х: состаренная бумага, лучи, звезда "80 из 100".
- `02-pulp-cover.html` - обложка pulp-еженедельника и космос: лента с названием, планета с кольцом, пульт.
- `03-vault-tec.html` - плакат Vault-Tec и зелёный терминал.

Страницы самодостаточные, шрифты подгружаются с Google Fonts. Открывать локально в браузере.
